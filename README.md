# Tinder Clone — React & Firebase Study Project

Projeto desenvolvido durante meus estudos de **React**, utilizando uma interface inspirada no Tinder como exercício prático para aplicar conceitos de desenvolvimento frontend e integração com **Firebase**.

O objetivo não foi reproduzir integralmente a plataforma original, mas utilizar um produto conhecido como referência para praticar a construção de interfaces modernas e a organização de uma aplicação React.

## Tecnologias

* React
* JavaScript
* HTML
* CSS
* Firebase
* Create React App
* Yarn / npm
* Git

## Conceitos praticados

* Componentização com React
* JSX
* Reutilização de componentes
* Organização de aplicações frontend
* Estilização com CSS
* Integração com Firebase
* Gerenciamento de assets e dados
* Desenvolvimento de interfaces inspiradas em aplicações reais

## Executando o projeto

```bash
yarn install
yarn start
```

ou:

```bash
npm install
npm start
```
